# notice-secretary-privacy

안드로이드 앱 **알림비서(Notice Secretary)** 의 개인정보처리방침을 공개하기 위한 저장소입니다.
방침 본문(`index.md`) 외에는 아무것도 들어 있지 않으며, 앱 소스 코드는 별도의 비공개 저장소에 있습니다.

공개 주소: https://History-Doctor.github.io/notice-secretary-privacy/

## 왜 저장소가 따로 있나

Google Play는 개인정보처리방침을 **로그인 없이 접근 가능한 URL**로 제출하도록 요구합니다.
GitHub Pages는 저장소 단위 기능이고 비공개 저장소에서 쓰려면 유료 플랜이 필요하므로,
공개해야 하는 문서 한 장만 이 저장소로 분리했습니다.

## 검색 노출

`robots.txt`와 `_layouts/default.html`의 `noindex` 메타 태그로 검색엔진 색인을 막아 두었습니다.
URL 자체는 누구나 열 수 있습니다 — Play의 요건이 그것이기 때문입니다.

## 수정할 때

`index.md`를 고쳐서 `main`에 push하면 GitHub Pages가 자동으로 다시 배포합니다.
**URL이 바뀌지 않으므로 Play Console에 재제출할 필요는 없습니다.**
본문 맨 아래 '최종 수정일'도 같이 갱신하세요.
